数据口径与更新方式

首板、二板、三板分别表示连续 1、2、3 个交易日涨停；四板及以上独立展示。分类取东方财富连续涨停字段，不将“多天多板”当作连续涨停。

涨停池按东方财富接口收录范围展示，不代表完整市场覆盖；原因按同一交易日、同一股票代码关联同花顺涨停原因标签。标签属于来源归因，未经独立核实，不能据此认定实际因果。行业仅为行业信息，不替代涨停原因。

抓取时间为北京时间。页面展示已保存快照，盘中数据会变化，盘后抓取也不保证来源已最终更新。“重新读取快照”只重载页面；获取新行情请运行本地脚本，或使用仓库每日自动任务。

如何抓取和历史复盘

Windows 双击“一键刷新行情.bat”；命令行执行 python sync_limit_up.py。指定交易日：python sync_limit_up.py --date 2026-10-28。无日期时寻找最近有数据的日期；指定日期不会回退。历史选项仅包含已成功保存的快照。
