## 🌟 项目简介

本工作台是一套专为专业投资者与实战交易者打造的 **A 股全生命周期投研操盘操作系统**。它打破了传统看盘软件信息割裂的壁垒，将**宏观资金流动性、全市场资金天梯、多赛道核心标的池、多因子量化评分、实盘持仓账本、凯利仓位计算器、操盘 SOP 战法、资产配置金字塔与龙虎榜席位密码**无缝融合在一个极简、现代、开箱即用的前端工作台中。

---

## 🚀 核心功能模块

### 1. 🌊 全市场流动性总枢纽与资金天梯
* **真实两市总成交额**（沪深两市成交额实时核算）
* **全市场赚钱效应**（精准统计全市场实际涨跌家数）
* **北向陆股通外资与杠杆融资动向**
* **6 大赛道资金天梯榜**：点击任一赛道卡片，下方股票池秒级联动筛选

### 2. 👑 6 大主线 56 只核心标的深度估值池
涵盖科技自主可控（AI算力/半导体/先进封装/特种高频材料）、新能源与先进制造（固态电池/低空经济/商业航天/智能底盘）、生物医药（创新药出海/GLP-1多肽/ADC）、高股息红利央企、战略资源（黄金铜）与跨境出海消费：
* **100% 官方真实历史与收盘行情**（价格、日涨跌幅、PE-TTM、总市值）
* **深度财务指标**：真实 ROE (净资产收益率)、销售毛利率 (%)、股息分红率 (%)、资产负债率 (%)
* **五维多因子综合评分模型**（成长、估值、安全边际、主力资金、护城河）
* **个股五维诊断雷达报告卡**（点击得分标签一键弹出机构诊断与操盘建议）
* **个股分时图 / 日 K 线 / 周 K 线即时交互弹窗**及直通东财/雪球/同花顺 F10 深度链接

### 3. 🎯 智能量化策略一键选股器
* 👑 **皇冠核心龙头** (五维量化评分 ≥ 94 分)
* 🚀 **极高 ROE 优质成长** (净资产收益率 ≥ 16%)
* 🛡️ **稳健高股息防守** (分红股息率 ≥ 3.5%)
* 🪙 **≤30元 低价潜力优选**
* ⚡ **今日强势放量突破** (当日实际涨幅 ≥ +2.0%)

### 4. 📊 实盘持仓管理与浮动盈亏账本 (PORTFOLIO LEDGER)
* 支持随时记录实盘买入标的（代码、成本价、股数、日期）
* **联动最新收盘价动态核算**：持仓总市值、今日盈亏金额、累计浮动盈亏额与收益率 (%)
* **双重持久化保障**：本地浏览器 localStorage 自动实时保存（刷新/重启不丢失） + 提供 **【📥 备份导出 JSON】** 与 **【📤 恢复导入】**

### 5. 🧮 机构仓位管理与盈亏比风险计算器 (KELLY & SIZING)
* 基于单笔最大允许风险率（如 2%）与凯利公式
* 输入计划买入价、止损价、目标价，自动计算**建议买入股数、建仓金额、占总资产仓位比例、盈亏比（Risk/Reward Ratio）及预期盈亏金额**

### 6. 📋 职业操盘看盘 SOP 执行清单与实战战法 (PLAYBOOK)
* **早盘 9:15 ~ 9:30**：集合竞价虚假挂单识别与情绪定调
* **盘中 9:30 ~ 11:30**：龙头主升确认与弱转强买点捕捉
* **尾盘 14:30 ~ 15:00**：尾盘抢筹异动与隔夜持仓风控

### 7. 🏛️ 攻守兼备资产配置金字塔与经典组合模板
* 激进成长主攻型 (80% 科技制造 + 20% 创新药)
* 稳健平衡全天候型 (40% 核心 + 30% 高股息红利 + 30% 跨境出海)
* 绝对避险抗通胀型 (60% 央企大行水电 + 30% 黄金铜 + 10% 现金)
* 顶层仓位纪律与动态再平衡法则

### 8. 🐉 龙虎榜主力席位与游资机构密码解密
* 机构专用席位真假识别
* 顶级游资风格速查（中关村大街格局锁仓 vs 拉萨天团出货刷屏）
* 外资北向做 T 规律与出货四大危险信号排雷

### 9. 📖 产业硬核术语词典 & 🧠 炒股投研分析框架
* 收录 HBM 高带宽内存、CoWoS 2.5D 先进封装、224G 高速直连铜缆 DAC、CPO 光模块、PPO/双马特种树脂、浸没式液冷等硬核术语
* 沉淀“卖铲人法则”、科技股估值三剑客、半导体硅周期、量价异动战法等机构投研方法论

## 🛠️ 文件结构与使用指南

```
.
├── 股票分析工作台.html        # 主投研工作台（全功能单文件 Web 应用）
├── index.html                 # 根目录首页入口
├── 一键刷新行情.bat            # Windows 双击一键同步最新真实行情
├── 一键同步最新真实行情.py     # 官方财经 API 实时数据抓取与多日历史对齐脚本
├── 半导体股票分析/
│   └── A股AI产业链全景图谱_低价精选.html
├── 指数基金投资指南.pdf       # 指数与资产配置参考资料
└── README.md                  # 项目说明文档
```

### 快速开始：
1. **直接查看工作台**：用任何现代浏览器（Chrome / Edge / Safari）双击打开 `股票分析工作台.html` 或 `index.html` 即可。
2. **每日更新最新行情**：双击运行 `一键刷新行情.bat`，脚本将自动连线交易所接口获取当日最新收盘价、两市总成交额、涨跌家数与各标的最新估值，并自动同步更新所有网页。
3. **数据导出与打印**：右上角支持一键将 56 只核心股票池及深度财务数据导出为 `CSV / Excel` 表格，或一键排版打印。
