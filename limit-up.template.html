数据口径与更新方式

首板、二板、三板分别表示连续 1、2、3 个交易日涨停；四板及以上独立展示。每日同步取东方财富连续涨停字段；同花顺历史补抓按实际交易日的涨停名单逐日核算，并核对明确的连续板形态。不将“多天多板”直接当作连续涨停，无法确认时列为板数待核实。

涨停池按当日来源接口收录范围展示，东方财富与同花顺历史池口径可能不同，不代表完整市场覆盖。原因取同一交易日、同一股票代码的同花顺涨停原因标签。标签属于来源归因，未经独立核实，不能据此认定实际因果。历史来源未返回的封板时间、成交额等字段留空。

抓取时间为北京时间。页面展示已保存快照，盘中数据会变化，盘后抓取也不保证来源已最终更新。“重新读取快照”只重载页面；获取新行情请运行本地脚本，或使用仓库每日自动任务。

如何抓取和历史复盘

Windows 双击“一键刷新行情.bat”；命令行执行 python sync_limit_up.py。补抓区间执行 python backfill_limit_up.py --start 2025-10-28 --end 2026-10-27，支持缓存续抓。历史选项仅包含已成功保存的快照。
